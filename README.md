# test-simple-form

### Запуск

1. Клонируйте текущий репозиторий по ссылке 

2. Перейдите в папку с проектом

3. пропишите текущую команду для запуска проекта в режиме разработки:`yarn dev`

### gh-pages
[Link!](https://yermaka-a.github.io/test-simple-form/)
Стек: 
1. Vue.js 3 + Composition API (фреймворк) 
2. TypeScript (язык) 
3. Pinia (стейт менеджер) 
4. TailwindCss
Форма состоит из: 
1. Заголовка и кнопки добавления учетной записи. 
2. Подсказки для поля метка. 
3. Списка учетных записей с лейблами полей.
